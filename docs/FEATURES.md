What the Remindly Windows app can do today, and the version that first had it (shown in the app under ⓘ Info → What's implemented). Add or update a row in every PR that adds a feature; CI checks this table.

| SrNo. | Area | What it does | Since |
|---|---|---|---|
| 1 | Tasks | Quick add, Active / Done, grouped Overdue · Today · Tomorrow · later days, priorities, snooze and Personal items. | 2.11.0 |
| 2 | Repeats | Daily, weekly on days, monthly on days or "second Monday / last Friday", quarterly, yearly, every N, spaced revision and end after N times; a done repeat comes back on its next day. | 2.11.0 |
| 3 | Learn | Learning items in their own Learn section, with the same priorities and repeats, including spaced revision. | 2.11.0 |
| 4 | Calls | Call-back reminders; the reminder card offers Call and WhatsApp. | 2.11.0 |
| 5 | Buy lists | Buy opens on your lists: what is left, progress, where items are bought, an estimated total and the shopping day; sort, pin, private lists. | 2.11.0 |
| 6 | List menu | Send to WhatsApp, share or preview, pin, edit, make default, duplicate, restart, mark all bought, merge and delete with Undo. | 2.11.0 |
| 7 | Inside a list | Group by date, shop, category or priority, recently bought suggestions, a warning for items already on another list, and Buy Now across every list. | 2.11.0 |
| 8 | Shops and Products | Keep your shops and products; product suggestions while typing. | 2.11.0 |
| 9 | Reminders | Pop-up cards bottom-right with Done · Snooze · Open; Ring keeps sounding until you act; runs in the notification area and can start with Windows. | 2.11.0 |
| 10 | Phone backup import | Settings → Backup → Import reads the Android backup file; records merge by id, the newer copy wins, importing twice changes nothing. | 2.11.0 |
| 11 | Automatic updates | Checks GitHub, verifies the SHA-256 and installs in the background; Setup closes a running Remindly, updates it and starts it again. | 2.11.0 |
| 12 | One download | One Remindly_x.y.z.zip with portable/, windows-x64/ (installer), Android/ and an empty macOS/ folder. | 2.12.0 |
| 13 | Beta updates | Optional "Include beta updates" in Settings → Updates, off by default and kept per PC. | 2.12.0 |
| 14 | Update button | The main window shows the installed version; "Update to vx.y.z" appears at the top right only when GitHub offers a newer version; checks at start-up. | 2.13.0 |
| 15 | Designs | Settings → Appearance: A Fluent (default), B Day Board, C Command Dark and D Today Hub, remembered on this PC. | 2.14.0 |
| 16 | Today Hub | Design D's Today home and Shop Overview: due today, call-backs, next 7 days, learning progress, list progress rings and Buy now by store. | 2.14.0 |
| 17 | Shortcuts | Ctrl+1…4 open the menu entries and Ctrl+M switches Task / Shop in every design; Ctrl+K opens design C's command bar. | 2.14.0 |
| 18 | Task menu | Right-click a task for Edit · Done · Snooze · Move to today · Open link · Delete. | 2.14.0 |
| 19 | Version history | Settings → Updates → Version history: choose an exact stable or beta version, with rollback warnings and a data snapshot before installing. | 2.15.0 |
| 20 | Account and sync | Sign in with Google and sync live with the Android app through Firestore; Settings → Account & Sync shows the state and Sync now. | 2.16.0 |
| 21 | Sync in the header | The top bar shows your account and the sync state. | 2.16.0 |
| 22 | Deleting with sync | Delete forever and Empty the Bin hide the records on this PC and keep the deletion for the phone. | 2.16.0 |
| 23 | Short beta names | Test builds are named x.y.z-betaNNN (for example 2.17.0-beta001); updates rank them above older beta names and below the stable version. | 2.17.0 |
| 24 | Release notes | Settings → Updates → What's New / Implementations shows what a release contains, also for a version chosen in Version history. | 2.17.0 |
| 25 | Info window | ⓘ next to the version, F1 or Settings → About: this build, what's implemented, what's new and what's under the hood, with Copy build info. | 2.18.0 |
| 26 | Beta chip | A test build shows a small Beta chip next to the version in every design. | 2.18.0 |
